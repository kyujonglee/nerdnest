# 핵심 기능 상세 명세서

## 프로젝트명 : NerdNest

### 프로젝트 기획의도 : **nerdnest**는 개발자, 기획자, 디자이너 등 IT 관련 종사자들이 업무나 공부 중에 마주치는 궁금한 점을 쉽게 질문하고, 서로 답변을 주고받을 수 있는 지식 공유 플랫폼입니다. 기존 Q&A 사이트들은 복잡한 UI와 낮은 접근성으로 인해 답을 찾는 과정 자체가 부담이 되는 경우가 많았습니다. 이에 보다 **간결하고 직관적인 UI**, **높은 가독성**, 그리고 **카테고리별로 정리된 콘텐츠**를 통해 사용자가 필요한 정보를 쉽게 찾고 공유할 수 있는 공간을 만들고자 했습니다. nerdnest는 단순한 질문과 답변을 넘어, 모든 IT 종사자들이 자신의 실무 능력과 지식을 함께 성장시킬 수 있는 커뮤니티를 지향합니다.

## **핵심 기능 상세 명세**

각 기능은 사용자 경험 흐름과 함께 피그마 화면을 기준으로 상세 동작을 정의합니다.

### **1. 회원가입 / 로그인**

- **목표**: 사용자가 서비스에 쉽고 안전하게 접근할 수 있도록 계정을 생성하고 관리한다.
- **화면 참조 :** 회원가입 및 로그인 화면

- **상세 동작**:
    - **1.1. 회원가입**:
        - **필수 입력 항목**:
            - **이름 (name)**: 텍스트 입력
            - **이메일 (email)**: 이메일 형식 유효성 검사
            - **아이디 (username)**: 영문 소문자, 숫자 조합 5~20자. (유효성 검사: 중복 확인 - 하단 문구 "중복된 아이디 입니다. 다른 아이디를 입력해주세요", 길이, 형식)
            - **비밀번호 (password)**: 8~20자, 영문 대소문자, 숫자, 특수문자 중 3가지 이상 포함.
            - **비밀번호 확인**: 비밀번호와 일치 여부 확인. (유효성 검사: 불일치 시 하단 문구 "비밀번호가 일치하지 않습니다. 다시 확인해주세요")
        - **선택 입력 항목**:
            - **직업 (job)**: 드롭다운 (개발자, 디자이너, 기획자)
            - **연차 (level)**: 숫자 입력 (0 이상 정수. 예: 1년차는 '1' 입력)
        - **약관 동의**: 필수 동의 체크박스 (추후 개발 예정)
        - **성공 시**: 모든 데이터가 알맞게 입력되면 "회원가입이 완료되었습니다." 메시지 노출 후 로그인 페이지로 자동 이동.
        - **실패 시**: 각 유효성 검사 실패 시 해당 필드 하단에 **에러 메시지** 노출.
        - **기타**: 이미 회원인 사용자는 왼쪽 상단 '로그인 하러가기' 클릭 시 로그인 페이지로 이동 가능.
        - **URL**: `POST /api/members`
    - **1.2. 로그인**:
        - **입력 항목**: 아이디 (username), 비밀번호 (password)
        - **유효성 검사**: 아이디, 비밀번호 불일치 시 하단 문구 "아이디 또는 비밀번호 잘못입력했습니다".
        - **자동 로그인**: 선택/해제 기능 (추후 개발 예정)
        - **링크**: '회원가입', '아이디 찾기', '비밀번호 변경' 클릭 시 해당 경로로 이동.
        - **소셜 로그인**: (추후 개발 예정)
        - **성공 시**: 세션/JWT 토큰 발급 및 유지. 메인 페이지로 이동.
        - **실패 시**: "아이디 또는 비밀번호 잘못입력했습니다" 메시지 노출.
        - **URL**: `POST /api/members/auth`
    - **1.3. 아이디 찾기**:
        - **입력 항목**: 이메일
        - **액션**: '아이디 찾기' 버튼 클릭 시 이메일로 아이디 표시 (일부만 보여지고 나머지는  처리).
        - **URL**: `POST /api/members/search-id`
    - **1.4. 비밀번호 찾기**:
        - **입력 항목**: 아이디, 이메일
        - **액션**: '비밀번호 찾기' 버튼 클릭 시 비밀번호 변경 가능 URL 이메일로 전송 (추후 개발 예정).

### **2. 메인 페이지**

- **목표**: 사용자가 서비스의 핵심 콘텐츠(최신/인기/추천 게시글)를 한눈에 파악하고, 주요 카테고리로 쉽게 이동하도록 한다.
- **화면 참조**: 메인 페이지 화면

- **화면 구성**:
    - **2.1. 상단 (Header)**:
        - **로고**: 클릭 시 메인 페이지로 이동.
        - **카테고리별 상세 페이지 이동 경로**: '기획', '디자인', '개발', '커뮤니티', 'Tip'.
            - 글자 위에 마우스 오버 시 해당 카테고리로 이동.
            - '커뮤니티', 'Tip'은 변동 가능성 있음 (예: '스터디 모집' 등으로 변경 가능).
            - **URL**: `GET /api/boards/category/{categoryId}`
        - **사용자 정보**:
            - **비 로그인 시**: '로그인', '회원가입' 버튼 생성.
                - 로그인 URL: `GET /api/members/auth`
                - 회원가입 URL: `GET /api/members`
            - **로그인 시**: 사용자 이름, 직업, 연차 표시.
                - **URL**: `GET /api/members/myinfo`
        - **검색창**: 키워드 검색 (글 제목, 내용, 태그, 작성자 닉네임).
        - **사용자 액션 버튼**: 로그인 후에는 '프로필 (마이페이지 이동)', '새 글 작성'.
    - **2.2. NN 카테고리 (메인 섹션)**:
        - **목표**: 주요 카테고리별로 대표 게시글을 보여주고, 해당 카테고리 상세 페이지로 이동을 유도한다.
        - **카테고리**: '기획', '디자인', '개발', '커뮤니티', 'Tip'.
        - **URL**: `GET /api/boards/category/{categoryId}`
    - **2.3. NEW 최신글 (메인 섹션)**:
        - **목표**: 서비스에 새로 등록된 게시글을 시간 순으로 보여준다.
        - **데이터**: 최근 등록된 게시글 4개.
        - **필요 데이터**: 게시글 제목, 사용자 이름, 직업, 연차, 좋아요 수, 댓글 수.
        - **액션**: 각 게시글 클릭 시 해당 게시글 상세 페이지로 이동.
        - **URL**: `GET /api/boards/latest`
    - **2.4. HOT 이번 주 인기글 (메인 섹션)**:
        - **목표**:  좋아요 수가 가장 높았던 게시글을 보여준다.
        - **데이터**: 좋아요 수가 가장 높은 게시글 4개.
        - **필요 데이터**: 게시글 제목, 사용자 이름, 직업, 연차, 좋아요 수, 댓글 수.
        - **액션**: 각 게시글 클릭 시 해당 게시글 상세 페이지로 이동.
        - **URL**: `GET /api/boards/like`
    - **2.5. Nerd’ Kick (메인 섹션)**:
        - **목표**: 조회수와 좋아요 수가 가장 높은 게시글을 보여준다. (최신글, 인기글과 중복될 수 있으며, 추후 사라질 가능성 있음)
        - **데이터**: 조회수와 좋아요 수가 가장 높은 게시글 3개.
        - **필요 데이터**: 게시글 제목, 사용자 이름, 직업, 연차, 좋아요 수, 댓글 수.
        - **액션**: 각 게시글 클릭 시 해당 게시글 상세 페이지로 이동.
        - **URL**: `GET /api/boards/kick`
    - **2.6. 하단 (Footer)**:
        - **로고 및 문구**: 서비스 로고와 간략한 설명 문구.
        - **링크**: 소개, 오류제보, 문의하기 (추후 개발 예정).
        - **SNS 아이콘**: (추후 개발 예정).
        - **버튼**: TOP 버튼, 문의하기 버튼 (추후 개발 예정).

### **3. 카테고리별 상세 게시글 목록 페이지**

- **목표**: 사용자가 특정 카테고리에 속한 게시글만 모아보고, 다양한 필터링 및 정렬 옵션으로 원하는 정보를 빠르게 찾도록 한다.
- **화면 참조**:
- **상세 동작**:
    - **진입 경로**: 메인 페이지 카테고리 메뉴 또는 특정 카테고리 태그 클릭 시.
    - **검색 기능**: 글자 검색 시 비슷한 게시글 검색 (메인과 똑같이 9개씩 정렬) (개발 예정).
    - **글쓰기 버튼**: 버튼 클릭 시 게시글 등록 페이지로 이동.
    - **정렬 옵션**: '추천순', '오래된 순', '최신순' 정렬 (개발 예정).
    - **게시글 목록**: 9개씩 보여지게 하기.
        - **표시 항목**: 작성자 정보, 게시글 제목, 게시글 내용, 날짜, 조회수, 댓글 수, 좋아요 수.
    - **페이징**: 1, 2, 3 버튼 페이징 (개발 예정).
    - **URL**: `GET /api/boards/category/{categoryId}`

### **4. 게시글 상세 페이지**

- **목표**: 선택된 게시글의 전체 내용과 댓글을 확인하고, 사용자가 직접 상호작용(추천, 댓글 작성 등)할 수 있도록 한다.
- **화면 참조**: 게시글 상세 페이지 화면

- **상세 동작**:
    - **상단 정보**:
        - **카테고리 이름**: 게시글의 카테고리 명.
        - **사용자 정보**: 작성자 프로필 (닉네임, 직무, 연차).
        - **제목**: 게시글 제목.
        - **내용**: 텍스트, 이미지, 파일 첨부 (다운로드 가능) → (이미지, 파일은 추후 개발 예정)
    - **댓글 섹션**:
        - **댓글 목록**: 댓글, 대댓글 조회.
            - **표시 항목**: 사용자 정보, 댓글 작성 시간, 댓글 내용.
        - **댓글 작성**: 로그인 사용자만 가능. 텍스트 입력창. (유효성 검사: 내용 빈 값 불가, 길이 제한).
        - **댓글 수정/삭제**: 본인 댓글만 가능.
        - **URL**: `POST /api/comments`
    - **오른쪽 상단**:
        - 조회수, 댓글 수, 좋아요 수 표시.
        - '댓글 보러가기' 버튼 (개발 고민 중).
        - SNS 공유 링크 (추후 개발 예정).
    - **액션 버튼**:
        - **수정/삭제**: 게시글 작성자 또는 관리자만 노출. 클릭 시 팝업 확인 후 수정 페이지 이동 또는 삭제.

### **5. 게시글 작성 페이지**

- **목표**: 사용자가 새로운 질문이나 지식 공유 게시글을 작성할 수 있도록 한다.
- **상세 동작**:
    - **입력 항목**:
        - **카테고리**: 드롭다운 (대분류 - 기획/개발/디자인/자유, 중분류 - 프론트엔드/백엔드/UI/UX 등).
        - **제목 (title)**: 텍스트 입력 (필수, 최대 100자).
        - **내용 (content)**: 텍스트 입력 (이미지 첨부, 파일 첨부 추후 개발 예정)
        - **태그**: 텍스트 입력 후 엔터/쉼표로 추가 (선택, 최대 5개, 기존 태그 자동 완성 지원) → (추후 개발 예정)
    - **버튼**: '등록', '취소'.
    - **성공 시**: 입력 후 '등록' 버튼 누르면 "게시글이 성공적으로 등록되었습니다." 메시지 후 카테고리 메인 화면으로 이동.
    - **실패 시**: 필수값 누락 등 유효성 검사 실패 시 에러 메시지 노출.
    - **URL**: `POST /api/boards`

### **6. 마이페이지**

- **목표**: 사용자가 자신의 활동 내역(작성 글, 댓글, 좋아요 등)을 확인하고 개인 정보를 관리할 수 있도록 한다.
- **상세 동작**: 추후 개발 논의 중.
